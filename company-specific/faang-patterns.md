# FAANG Interview Patterns

## Google
- Graph problems (BFS/DFS heavy)
- Dynamic programming
- System design: distributed systems

## Amazon
- Leadership principles alignment
- Array/string manipulation
- System design: scalability

## Meta
- Graph/tree traversal
- Sliding window
- System design: social features

## Apple
- Linked lists, trees
- Design patterns (OOP)
- System design: iOS architecture

## Microsoft
- Arrays, strings, trees
- Two pointers
- System design: cloud services

## Tips
1. Practice 3-5 problems per pattern
2. Explain thinking out loud
3. Always discuss trade-offs
4. Write clean, tested code
