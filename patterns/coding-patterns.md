# Common Coding Patterns

1. **Sliding Window** - Subarray problems
2. **Two Pointers** - Sorted array, palindrome
3. **Fast & Slow** - Cycle detection
4. **Merge Intervals** - Overlapping ranges
5. **Cyclic Sort** - Missing/duplicate numbers
6. **BFS/DFS** - Tree/graph traversal
7. **Top K Elements** - Heap problems
8. **Binary Search** - Sorted search space
9. **Backtracking** - Combinations/permutations
10. **DP** - Overlapping subproblems
